# Paradise Nursery

Paradise Nursery is a modern e-commerce web application for purchasing houseplants online. The app features a beautiful plant-themed design with a curated collection of succulents, air-purifying plants, and aromatic varieties. Users can browse plants by category, add items to their shopping cart, manage quantities, and proceed to checkout.

## Tech Stack

- React 19 - UI library
- Redux Toolkit - State management
- React Router DOM - Client-side routing
- Vite - Build tool
- CSS3 - Custom properties for theming

## Features

- Product listing with 7 houseplants across 3 categories
- Shopping cart with real-time updates
- Quantity management
- Dynamic price calculations
- Fully responsive design
- Cohesive design system with teal and green color palette

## Run Locally

1. Clone the repository
2. Install dependencies: npm install
3. Start dev server: npm run dev
4. Open browser at http://localhost:5173

## Build for Production

npm run build

## Pages

- Landing Page (/) - Hero section with company info
- Product Listing (/products) - Browse plants
- Shopping Cart (/cart) - Manage cart items
